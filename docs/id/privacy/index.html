Kebijakan Privasi ABS+

Berlaku sejak 27 Oktober 2026

ABS+ (“aplikasi”) adalah klien untuk Audiobookshelf, server media yang dijalankan oleh Anda atau seseorang yang Anda kenal. Kebijakan ini menjelaskan data apa saja yang ditangani aplikasi dan ke mana data itu pergi. Singkatnya: pengembang ABS+ tidak menerima data apa pun dari Anda. Aplikasi ini tidak memiliki analitik, iklan, pelaporan kerusakan, maupun SDK pihak ketiga yang mengumpulkan data.

Data yang dikirim aplikasi, dan ke mana

Aplikasi hanya berkomunikasi dengan alamat server Audiobookshelf yang Anda masukkan saat masuk. Aplikasi mengirimkan ke server tersebut:

  • nama pengguna dan kata sandi Anda saat masuk (untuk mendapatkan token login);
  • permintaan untuk pustaka, item, seri, sampul, dan berkas audio Anda;
  • progres mendengarkan dan favorit Anda (disimpan sebagai penanda di server);
  • jika Anda menautkan akun lain untuk berbagi progres: login akun tersebut, serta pembaruan progres untuk judul yang Anda pilih untuk dibagikan dengan mereka.

Server itu dijalankan oleh Anda atau oleh siapa pun yang mengelolanya, bukan oleh pengembang ABS+. Penanganan data di sana diatur oleh kebijakan pengelolanya. Jika Anda memasukkan alamat yang diawali http:// alih-alih https://, lalu lintas ke alamat itu tidak dienkripsi.

Data yang disimpan di perangkat Anda

  • Alamat server, dan token login untuk akun Anda serta akun tertaut mana pun. Kata sandi tidak disimpan.
  • Cache data pustaka dan gambar sampul, agar layar dimuat dengan cepat dan tetap berfungsi offline.
  • Berkas audio yang diunduh, di penyimpanan pribadi aplikasi.
  • Setelan, posisi pemutaran, favorit, dan daftar item yang baru diputar.

Keluar dari akun akan menghapus data akun, token, cache, dan setelan dari perangkat. Unduhan tetap disimpan sampai Anda menghapusnya (Setelan → Unduhan) atau mencopot aplikasi. Mencopot aplikasi menghapus semuanya. Di iOS, sistem dapat tetap menyimpan token login di Keychain setelah aplikasi dicopot; aplikasi akan menghapusnya jika dipasang lagi.

Di Android, pencadangan data aplikasi pada perangkat dinonaktifkan. Di iOS, token login disimpan di Keychain hanya untuk perangkat ini dan unduhan tidak disertakan dalam pencadangan. Setelan dan daftar (seperti favorit dan yang baru diputar) bisa menjadi bagian dari cadangan iCloud atau komputer Anda sendiri yang terenkripsi.

Izin

Di Android:

  • Internet dan status jaringan: untuk menjangkau server Anda dan mengetahui saat Anda offline.
  • Layanan latar depan (pemutaran media) dan wake lock: agar audio tetap diputar saat layar mati dan untuk menampilkan kontrol pemutaran.

Unduhan menggunakan pengelola unduhan sistem Android.

Di iOS:

  • Audio latar belakang: agar pemutaran berlanjut saat layar terkunci dan untuk menampilkan kontrol di layar kunci.
  • Jaringan lokal: hanya diminta jika server Anda berada di jaringan lokal Anda.

Unduhan menggunakan transfer latar belakang iOS, sehingga tetap berlanjut saat aplikasi ditutup.

Situs web ini

absplus.app menghitung kunjungan dengan Lumen, penghitung halaman kecil yang dijalankan sendiri oleh pengembang. Situs ini tidak memakai cookie, tidak menyimpan alamat IP, dan tidak menyimpan apa pun yang dapat mengenali Anda: setiap pengunjung dihitung dengan kode yang berganti setiap hari. Ini terpisah dari aplikasi, yang tetap tidak mengirim apa pun kepada pengembang.

Anak-anak

Aplikasi ini tidak ditujukan untuk anak di bawah usia 13 tahun dan tidak dengan sengaja mengumpulkan data dari siapa pun.

Perubahan

Jika kebijakan ini berubah, versi barunya akan diposting di alamat ini dengan tanggal berlaku yang baru.
