オーディオブック再生速度・再生時間計算ツール

オーディオブックやポッドキャストを速い速度で聴くときにかかる時間は、通常速度での長さを再生速度で割って求めます。45分を1.75xで聴くと25分43秒(45 ÷ 1.75、下の計算では26分に四捨五入)、6時間のオーディオブックを1.5xで聴くと4時間です。全体の長さ、現在の位置、毎日聴く時間を入力すると、残り時間、聴き終える日、期日に間に合わせるのに必要な速度がわかります。

計算のしかた

オーディオブックやポッドキャストの再生時間は常に通常速度(1x)で表示されるため、実際にかかる時間は残りの長さを再生速度で割った値になります。12時間30分の本を1.25xで聴くと10時間です(12.5 ÷ 1.25)。このツールは割る前に現在の位置を差し引くため、速くなるのはまだ聴いていない部分だけで、表示する時間はもっとも近い分に丸めます。

聴き終える日は、毎日聴く時間をもとに今日から何日かかるかを数えて求めます。毎日欠かさず聴くことが前提です。聴き終える期日を選んだ場合は、今日からその日までの日数を両端を含めて数え、本の残りの分数を合計の聴取分数で割って、期日に収まる速度を求めます。計算はすべてブラウザ上で行われ、入力した内容がこのページの外に送信されることはありません。

計算例

下の例はいずれも 2026年11月24日に Chrome 上でこのツールを使って確認したもので、上のフォームに同じ値を入力すれば同じ結果が出ます。

  • 45分を1.75xで聴く場合: 全体の長さに0時間45分、現在の位置に0時間0分、再生速度に1.75xと入力します。45を1.75で割ると25.71分、つまり25分43秒になります(19分17秒、43%の短縮)。ツールではこれを丸めて26分と表示します。
  • 6時間のオーディオブックを1.5xで聴く場合: 6時間0分、1.5xと入力します。360分を1.5で割ると240分、ちょうど4時間です(2時間、33%の短縮。聴き終えるまで4日、毎日60分のペース)。
  • 12時間30分の本を3時間15分から1.25xで聴く場合(初期値): 進み具合は26.0%で、本の残り時間は9時間15分(555分)です。1.25xでは7時間24分かかり、10日で聴き終えます(毎日45分のペース、本全体では10時間)。
  • 10時間の本を2時間0分から、7日間の期日・毎日45分で聴く場合: 残りは8時間(480分)で、聴ける合計時間は315分(7日間)です。480を315で割ると1.52xになり、「聴き終える期日」を今日から六日後に設定するとツールにこの速度が表示されます。

速度を上げるとどれだけ短縮できるか

速度を一段上げるごとに、短縮できる幅は前の段階よりも小さくなります。多くの人が1.25xから1.75xのあいだに落ち着くのは、そのためです。

よくある質問

45分を1.75xで聴くと、どのくらいの時間になりますか?

45分を1.75xで聴くと25分43秒かかります(45を1.75で割ると25.71分)。短縮できるのは19分17秒です。このツールでは表示時間をもっとも近い分に丸めるため、26分と表示されます。

オーディオブックを1.5xで聴くと、何時間かかりますか?

通常速度での長さを1.5で割ります。6時間のオーディオブックなら4時間、12時間の本なら8時間です。2xならそれぞれ3時間と6時間になります。

位置と長さはどこで確認できますか?

どちらもプレーヤーに表示されています。ABS+ やその他の Audiobookshelf アプリではプレーヤー画面に、Audiobookshelf の Web プレーヤーではカバーの下に出ています。入力するのは、速度に合わせて調整された残り時間ではなく、通常速度での本の長さです。

プレーヤーに表示される残り時間が違うのはなぜですか?

プレーヤーによっては、再生速度に合わせて残り時間を調整して表示するものと、常に通常速度で表示するものがあります。このツールは通常速度での長さと位置を受け取り、再生速度で割る計算はツール側で行います。

期日までに本を聴き終えるには、どのくらいの速度が必要ですか?

本の通常速度での残り分数を、今日から目標の日までに聴く予定の合計分数(両端の日を含む)で割ります。「聴き終える期日」で日付を選べば、このツールが必要な速度を自動で計算します。
