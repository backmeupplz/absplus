計算のしかた

オーディオブックの長さは、常に通常の速度で再生した場合の時間で表されます。そのため、実際にかかる時間は、長さを再生速度で割った値になります。12時間30分の本を1.25xで聴くと、10時間かかります(12.5÷1.25)。このツールは、まず現在の位置を差し引くので、速くなるのはまだ聴いていない部分だけです。

聴き終える日は、毎日聴く時間でかかる日数を数え、今日を初日として求めます。毎日欠かさず聴くことが前提です。期日を選んだ場合は、今日からその日までの日数を両端を含めて数え、本の残り時間を、その間に聴く合計の分数で割ります。その結果が、間に合わせるために必要な速度です。計算はすべてブラウザ上で行われ、入力した内容がどこかに送信されることはありません。

速度を上げるとどれだけ短縮できるか

速度を一段上げるごとに、短縮できる時間は前の段よりも小さくなります。多くの人が1.25xから1.75xのあいだに落ち着くのは、そのためです。

よくある質問

オーディオブックを1.5xで聴くと、何時間かかりますか?

長さを1.5で割ります。12時間の本なら8時間、2xなら6時間です。

位置と長さはどこで確認できますか?

どちらもプレーヤーに表示されています。Audiobookshelf のアプリではプレーヤー画面に、Web プレーヤーではカバーの下に出ています。入力するのは、今の速度での残り時間ではなく、本そのものの長さです。

プレーヤーに表示される残り時間が違うのはなぜですか?

プレーヤーによって、残り時間を今の速度で表示するものと、通常の速度で表示するものがあります。このツールは通常の速度での長さを受け取り、速度の計算は自分で行いますので、通常の速度での数字を入力してください。
