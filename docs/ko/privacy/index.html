ABS+ 개인정보 처리방침

시행일: 2026년 10월 27일

ABS+(이하 "앱")는 본인 또는 지인이 운영하는 미디어 서버인 Audiobookshelf의 클라이언트입니다. 이 방침은 앱이 어떤 데이터를 다루고 그 데이터가 어디로 가는지 설명합니다. 요약하면 ABS+ 개발자는 사용자의 데이터를 전혀 받지 않습니다. 앱에는 분석 도구도, 광고도, 비정상 종료 보고도, 데이터를 수집하는 서드파티 SDK도 없습니다.

앱이 보내는 데이터와 그 전송처

앱은 로그인할 때 입력한 Audiobookshelf 서버 주소와만 통신합니다. 해당 서버로 보내는 정보는 다음과 같습니다.

  • 로그인할 때의 사용자 이름과 비밀번호(로그인 토큰을 받기 위해)
  • 라이브러리, 항목, 시리즈, 표지, 오디오 파일에 대한 요청
  • 청취 진행 상황과 즐겨찾기(서버에는 북마크로 저장됩니다)
  • 진행 상황 공유를 위해 다른 계정을 연결한 경우, 그 계정의 로그인 정보와 공유하기로 선택한 타이틀의 진행 상황 업데이트

이 서버는 ABS+ 개발자가 아니라 사용자 본인 또는 서버를 운영하는 사람이 운영합니다. 서버의 데이터 처리는 그 운영자의 방침을 따릅니다. https://가 아닌 http://로 시작하는 주소를 입력하면 해당 서버와의 통신은 암호화되지 않습니다.

기기에 저장되는 데이터

  • 서버 주소, 그리고 사용자 계정과 연결된 계정의 로그인 토큰. 비밀번호는 저장되지 않습니다.
  • 화면이 빠르게 열리고 오프라인에서도 작동하도록 저장해 두는 라이브러리 데이터와 표지 이미지 캐시
  • 앱 전용 저장 공간에 있는 다운로드한 오디오 파일
  • 설정, 재생 위치, 즐겨찾기, 최근 재생한 항목 목록

로그아웃하면 계정 데이터, 토큰, 캐시, 설정이 기기에서 삭제됩니다. 다운로드한 파일은 사용자가 직접 삭제(설정 → 다운로드)하거나 앱을 삭제할 때까지 유지됩니다. 앱을 삭제하면 모든 것이 지워집니다. iOS에서는 앱을 삭제한 뒤에도 시스템이 로그인 토큰을 키체인(Keychain)에 남겨 둘 수 있으며, 앱을 다시 설치하면 앱이 그 토큰을 삭제합니다.

Android에서는 앱 데이터의 기기 백업이 비활성화되어 있습니다. iOS에서는 로그인 토큰이 이 기기 전용으로 Keychain에 저장되고, 다운로드한 파일은 백업에서 제외됩니다. 설정과 목록(즐겨찾기, 최근 재생 항목 등)은 사용자 본인의 암호화된 iCloud 백업이나 컴퓨터 백업에 포함될 수 있습니다.

권한

Android의 경우:

  • 인터넷과 네트워크 상태: 서버에 연결하고 오프라인이 된 것을 알아차리기 위해
  • 포그라운드 서비스(미디어 재생)와 웨이크 락: 화면이 꺼진 상태에서도 오디오를 계속 재생하고 재생 컨트롤을 표시하기 위해

다운로드에는 Android의 시스템 다운로드 관리자를 사용합니다.

iOS의 경우:

  • 백그라운드 오디오: 화면이 잠긴 상태에서도 계속 재생하고 잠금 화면에 컨트롤을 표시하기 위해
  • 로컬 네트워크: 서버가 로컬 네트워크에 있을 때만 요청합니다

다운로드에는 iOS 백그라운드 전송을 사용하므로 앱을 닫아도 계속됩니다.

이 웹사이트

absplus.app은 개발자가 직접 운영하는 작은 페이지 카운터인 Lumen으로 방문 수를 집계합니다. 쿠키를 사용하지 않고, IP 주소를 저장하지 않으며, 사용자를 식별할 수 있는 정보를 전혀 보관하지 않습니다. 방문자는 매일 바뀌는 코드로 집계됩니다. 이는 앱과는 별개이며, 앱은 지금도 개발자에게 아무것도 보내지 않습니다.

어린이

앱은 만 13세 미만 어린이를 대상으로 하지 않으며, 누구에게서도 데이터를 의도적으로 수집하지 않습니다.

변경 사항

이 방침이 변경되면 새 버전을 새 시행일과 함께 이 주소에 게시합니다.
