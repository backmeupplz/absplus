## Description (max 4000)
ABS+ adalah pemutar kecil dan cepat untuk server Audiobookshelf Anda sendiri. Masuk dengan alamat server, nama pengguna, dan sandi, lalu buku dan podcast Anda langsung tersedia.

MENDENGARKAN
• Streaming audiobook dan episode podcast dari server Anda
• Buku yang terbagi menjadi banyak file diputar sebagai satu buku, dengan satu linimasa
• Kontrol dari Layar Terkunci, Pusat Kontrol, headphone, dan AirPlay
• Mundur dan maju 30 detik, dengan kecepatan putar dari 0,8× hingga 2×
• Melanjutkan dari posisi terakhir, bahkan setelah aplikasi ditutup

PROGRES YANG IKUT BERSAMA ANDA
• Progres disinkronkan ke server Anda, sehingga aplikasi Audiobookshelf lain dan pemutar web selalu mutakhir
• Lanjutkan mendengarkan menampilkan apa yang sedang Anda dengarkan, dari perangkat mana pun
• Bagikan progres sebuah buku dengan akun lain (misalnya saat mendengarkan bersama pasangan). Anda sendiri yang memilih judul dan mengonfirmasinya, lalu aplikasi bertanya dulu sebelum melompat ke posisi akun tersebut.

OFFLINE
• Unduh buku utuh atau satu episode podcast saja; unduhan tetap berjalan di latar belakang
• Saat server tidak dapat dijangkau, ABS+ otomatis beralih ke mode offline dan hanya menampilkan yang sudah diunduh
• Lihat dan hapus semua unduhan di satu tempat

MENATA KOLEKSI
• Kisi sampul untuk setiap pustaka, dengan pencarian berdasarkan judul atau penulis
• Seri dari server Anda
• Favorit yang tersinkron di semua perangkat Anda
• Baru diputar di perangkat ini

PRIVASI SEJAK AWAL
ABS+ hanya terhubung ke server tempat Anda masuk. Tanpa akun di pihak kami, tanpa analitik, tanpa iklan, dan tanpa pelacakan. Aplikasi ini open source.

ABS+ memerlukan server Audiobookshelf (audiobookshelf.org) yang dijalankan oleh Anda atau orang yang Anda kenal. ABS+ adalah aplikasi independen, tidak berafiliasi dengan maupun didukung oleh proyek Audiobookshelf.
