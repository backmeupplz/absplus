## Description (max 4000)
ABS+は、ご自身のAudiobookshelfサーバーで使う、軽量で高速なプレーヤーです。サーバーのURL、ユーザー名、パスワードでログインするだけで、サーバーにある本やポッドキャストがすぐに表示されます。

聴く
• サーバーにあるオーディオブックやポッドキャストのエピソードを、ストリーミングで再生できます
• 複数のファイルに分かれた本も、ひとつのタイムラインで1冊として再生します
• ロック画面、コントロールセンター、ヘッドフォン、AirPlayから操作できます
• 30秒戻す・30秒進むボタンがあり、再生速度は0.8倍から2倍まで変えられます
• アプリを閉じたあとでも、前回やめたところから再開できます

どこでも続きから
• 進捗はサーバーと同期されるので、ほかのAudiobookshelfアプリやWebプレーヤーにも最新の位置が反映されます
• 「続きを聴く」には、どのデバイスで聴いていたかにかかわらず、再生途中のタイトルが並びます
• 本ごとに、別のアカウントと進捗を共有できます（たとえばパートナーと一緒に聴く場合など）。共有するタイトルは自分で選んで確定し、相手の位置へ移動する前にはアプリが確認を求めます。

オフライン
• 本を丸ごと、またはポッドキャストのエピソードを1話ずつダウンロードでき、ダウンロードはバックグラウンドでも続きます
• サーバーに接続できないときは、ABS+が自動でオフラインモードに切り替わり、ダウンロード済みのものだけを表示します
• すべてのダウンロードを1か所で確認し、削除できます

整理
• ライブラリごとにカバーが一覧で並び、タイトルや著者で検索できます
• サーバーにあるシリーズをそのまま表示します
• お気に入りはデバイス間で同期されます
• このデバイスで最近再生した項目も表示されます

プライバシーを重視した設計
ABS+が通信するのは、ログインしたサーバーだけです。ABS+専用のアカウントは不要で、分析も広告もトラッキングもありません。アプリはオープンソースです。

ABS+を使うには、ご自身または知り合いが運用しているAudiobookshelfサーバー（audiobookshelf.org）が必要です。ABS+は独立したアプリであり、Audiobookshelfプロジェクトとは提携しておらず、その承認も受けていません。
